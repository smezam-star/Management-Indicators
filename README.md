Puedes acceder a la versión completamente funcional y adaptada para ordenadores y móviles haciendo clic en el siguiente enlace:

👉 **[https://smezam-star.github.io/Management-Indicators/simulador/](https://smezam-star.github.io/Management-Indicators/simulador/)**

---

### Características Principales:
- **Asistente de IA (Copiloto):** Un chat inteligente basado en la metodología del DNP y DANE para formular indicadores estructurados mediante el método de 5 pasos.
- **Auditoría CREMAS:** Verificación automática de la calidad de tus indicadores (Claro, Relevante, Económico, Medible, Adecuado, Sensible).
- **Centro de Aprendizaje:** Integración de la teoría metodológica y guías oficiales accesibles en todo momento.
- **Diseño Responsivo (Mobile-First):** Interfaz perfectamente adaptable a pantallas de celulares, con menús táctiles deslizables y componentes modulares.
- **Portafolio:** Guarda y administra tus indicadores desarrollados de manera local.

## 📁 Estructura del Proyecto
Todo el código fuente ejecutable (HTML, CSS, JS) de la aplicación web se encuentra dentro de la carpeta `/simulador`. La raíz del repositorio contiene documentos PDF metodológicos de referencia y recursos base.
